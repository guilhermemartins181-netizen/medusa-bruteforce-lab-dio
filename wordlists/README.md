# Wordlists do laboratório

Listas **pequenas e didáticas**, feitas para o ataque terminar rápido no lab e ilustrar o conceito de ataque de dicionário.

- `usuarios.txt` — nomes de conta comuns em servidores/serviços Linux.
- `senhas.txt` — senhas fracas/padrão típicas de ambientes mal configurados.

Em um teste real (autorizado), usam-se listas maiores como a `rockyou.txt` ou listas geradas sob medida com `crunch` — ver [`../docs/03-wordlists.md`](../docs/03-wordlists.md).

> Estas listas servem **apenas** para uso contra o alvo de treino (Metasploitable 2) em rede isolada.
